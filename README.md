---

## 关于这个仓库

我希望用文字证明一件事：**我不只是在玩游戏，我在理解游戏。**

这里的每一篇文章都来自真实的思考——为什么这个机制让人上瘾，为什么这个关卡让人沮丧，为什么这个游戏值得被反复研究。
